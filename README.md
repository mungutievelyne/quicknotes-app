
## QuickNotes

QuickNotes is a simple note-taking web application that helps users capture, organise, search and manage their notes.

## Features

- Add notes with Personal, Work or Study categories.
- Validate note input to prevent empty notes and notes longer than 200 characters.
- Display a note count that updates automatically.
- Delete individual notes.
- Search notes by text.
- Save notes in the browser using localStorage, so they remain after refreshing the page.
- Responsive design for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For automatic browser refresh during development, you can use the Live Server extension in Visual Studio Code.

## How to Use

1. Enter your note in the text field.
2. Select a category.
3. Click **Add Note**.
4. Use the search field to find notes.
5. Click **Delete** to remove a note.

Notes are stored locally in your browser. They are not automatically synced across browsers or devices.
